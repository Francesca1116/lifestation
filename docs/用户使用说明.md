## 3. Dashboard 默认首页

打开后看到的内容（按从上到下）：

1. **标题**：今年 · N 个目标 · M% 完成（或"计划未设置"提示）
2. **大进度环**：年度完成度（来自 `db_year_plan` 平均 + 关键节点计算）+ 6 KPI
3. **6 KPI 卡片**（每个都有图标 + 数字）：
   - 已过去 N% · 距年底还有 X 天

   - 本周任务（已完成数）
   - 习惯打卡（近 7 天）
   - 本周支出（CNY，已经汇率折算）

5. **跨模块今日**（8 条以内，来自 5 类源合并：逾期任务 / 今日日程 / 未打卡习惯 / P0 项目 / Inbox 待处理）

## 4. 进入群组 → 左栏导航

点任一板块卡 → 自动切到该群组 + 出现 260px 折叠式侧栏。

### 左侧侧栏的元素

- 📍 **总览**（点这个返回 dashboard）
- 🏞️🎓💼🌐 **群组**（4 个，点击展开/折叠显示子模块）
- 📅 **今年计划入口卡片**（底部）：
  - 如果没设置：点击"+ 添加今年计划"按钮 → 弹模态录入
  - 如果已设置：显示当前进度 + 截止 + 添加按钮

### 折叠

侧栏右上角有一个圆形切换按钮 `‹`，点击折叠为 60px 仅图标显示，再点 `›` 展开。

### 子模块 tab

每个群组下方有横向 tab（如生活群有 6 个：今日概览 / 日程 / 习惯 ...），点击切到对应模块。

# 生活站 · 架构设计

## 1. 设计目标

一体化工作台，覆盖：
- 生活（今日 / 日程 / 习惯 / 健身 / 记账 / 书影音）
- 学习（课程笔记 / 学习任务 / 学习目标 / 学习打卡 / 学习复盘）
- 工作（项目任务）
- 复盘（每周 / Inbox）
- Personal Observatory（Topic / Stage / Momentum / Constellation / River / Funnel / Connections）

**核心约束**：
- 单文件 HTML（不依赖任何外部资源，离线可用）
- 数据双栈（优先 WorkBuddy 资料库 SDK，降级 localStorage）
- 视觉统一（莫奈水彩 + 玻璃卡片）

## 4. Personal Observatory 计算层

### 4.1 Stage 系统（E1-E6）

| Stage | 含义 | Weight | cap |
|-------|------|--------|-----|
| E1 Explore | 浏览 / 收集 | 1 | 10 |
| E2 Learn | 入门理解 | 2 | 8 |
| E3 Synthesize | 综合 | 4 | 5 |
| E4 Apply | 应用 | 6 | 4 |
| E5 Output | 产出 | 9 | 3 |
| E6 Reuse | 复用 | 8 | 5 |

### 4.2 动量（Momentum）公式

```
topicMomentum(t) = Σ event.weight × 0.5^(daysSince(event)/21)
```

- 半衰期 21 天
- 自动衰减，过时事件影响力指数级下降

### 4.3 状态判定（6 档）

| 状态 | 判定逻辑 |
|------|----------|
| Emerging | 0 < momentum < 5 且 depth < 10 |
| Accelerating | momentum > 10 且 7 天内事件 > 5 |
| Developing | 10 ≤ depth < 30 |
| Mature | depth ≥ 30 |
| Dormant | momentum < 1 |
| Reviving | momentum 上升中但 depth 较低 |

// topicDepth: StageWeight × cap 公式
function topicDepth(topic) {
  const cap = { E1: 10, E2: 8, E3: 5, E4: 4, E5: 3, E6: 5 };
  const weight = { E1: 1, E2: 2, E3: 4, E4: 6, E5: 9, E6: 8 };
  return topic.events.reduce((sum, e) => {
    return sum + weight[e.stage] * Math.min(e.count, cap[e.stage]);
  }, 0);
}

// topicMomentum: 21 天半衰期
function topicMomentum(topic, now = Date.now()) {
  return topic.events.reduce((sum, e) => {
    const days = (now - e.timestamp) / 86400000;
    return sum + e.weight * Math.pow(0.5, days / 21);
  }, 0);
}

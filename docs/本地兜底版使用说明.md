> 当前交付的是**方案 B 兜底版本**：数据存在浏览器 localStorage（key 前缀 `dc_lifestation_*`），不依赖任何云服务；可以立刻在浏览器里打开看效果、做完整操作；等资料库账号修通后，**回到 IDE 会话里告诉我「接上」**，我会在不改你现有数据的前提下把工作台升格成正式在线 page。

## 1. 立即使用（现在就能用）

### 怎么打开

- **Mac**：双击 `生活站.html`，自动用默认浏览器打开
- **文件协议**：`file:///Users/hujiayun/WorkBuddy/2026-08-31-14-03-28/生活站.html`
- **iPhone**：可以 AirDrop 这个文件到 iPhone，用「文件」App 打开 → Safari 全屏；或部署后用在线链接（见第 4 节）

### 6 模块能力一览

| 入口 | 主要功能 |
|---|---|
| **今日概览（hero）** | 合并「逾期 + 今日 + 未打卡习惯」，顶部置顶；逾期红边、Today 紫边；点 check 一键完成/打卡 |
| **日程** | 自绘月历（参考苹果日历）+ 上/下月切换；每天支持多重事件；事件类型支持「事件 / 待办」与「每天 / 每周」重复 |
| **习惯** | 三种打卡方式（**勾选 / 计数 / 数值**）+ 连续天数 + 总计 + 30 天热力图（5 阶紫色梯度） |
| **健身** | 体重体脂记录 + 7 日均线 + BMI + 今日热量缺口 + 折线趋势图（最近 14 次） |
| **记账** | CNY + GBP 双币种分桶 + **手动汇率折算**（默认 1 GBP = 9.10 CNY）+ 月度对比 + **消费结构饼图** + **月度账单报表**（生成 HTML） |
| **书影音** | 评分 + 状态 + 短评 + 年度统计 + **年度阅读表单**（生成 HTML，按书 / 影 / 音三类分组） |

### 6 个必测交互

1. 顶部右上角「**离线模式**」dot 等于"数据存本浏览器"标识；一旦资料库账号修通会变成"已同步"
2. 「**今天要处理**」点 check 框 → 直接勾掉 / 一键打卡，不需要进模块
3. 任意模块右上角「**+ 新增**」→ 弹通用表单 → 填完按「保存」自动入库 + 立刻渲染
4. 任意模块「**📊 月账单**」或「**📚 年度表单**」→ 弹出新窗口显示报表（被拦截则自动下载 HTML）
5. 顶栏「**导出**」→ 下载 JSON 备份；「**导入**」→ 选择 JSON 覆盖当前数据（自动二次确认）
6. 关闭再开浏览器，数据**完整保留**（存 localStorage）

### 隐私边界（必须知道）

- 数据完全在**你的浏览器本地**，不传给任何服务器（除非修通资料库）
- 部署到资料库在线 page 后，**任何人拿到链接都能打开**——但写入操作只走资料库 SDK + 你账号身份鉴权
- 因此：示例数据非真实隐私；正式上线后请清掉示例再录入真数据
- localStorage 在以下情况会丢：清浏览器缓存 / 卸载浏览器 / 重置设备。**建议每周导出一次 JSON 备份**

## 3. 修通资料库账号后，怎么"接上"？

### 最简单做法（推荐）

回到这个 IDE 会话，对我说：

> **接上** / **续上之前的工作** / **跑续用脚本**

我会自己：
1. 重新探测 `connect_open_platform` 是否可用
2. 拿到 token 写入 `/tmp/wb_token`
3. 顺序执行 `02 → 03 → 04 → 05` 续用脚本（在 `.workbuddy/scripts/`）
4. 把公开 URL 交付给你

### 如果你想自己跑

```bash
source .workbuddy/scripts/env.example   # 复制到 /tmp/lifestation_env.sh 后 source

# 取 token → 写到 /tmp/wb_token（在 IDE 会话里让 agent 拿）
# 续跑：
bash .workbuddy/scripts/02_create_lifestation_dbs.sh
python3 .workbuddy/scripts/03_attach_database_ids.py \
  --manifest .workbuddy/scripts/manifest.json \
  --html    生活站.html \
  --out     生活站.ready.html
bash .workbuddy/scripts/04_import_page.sh
bash .workbuddy/scripts/05_publish_page.sh
```

每一跑成功会写一份 `manifest.json`，记录 9 张 database_id + page_node_id + publish_url。任意一步失败可独立重跑。

### 数据迁移

修通后，你大概率想保留现状的 localStorage 数据：

1. 在本地版顶栏点「**导出**」下载 JSON
2. 续用脚本跑完拿到在线 URL
3. 在线版的顶栏也是「**导入**」按钮（同一个 HTML），上传 JSON → 自动确认 → 全部数据上云

- 在线 page 拿到的是 `https://xxx.workbuddy.link/p/{id}` 形式的链接，**公网可达**

## 5. 文件清单（你要保留与备份）

| 文件 | 是否你的数据 | 备注 |
|---|---|---|
